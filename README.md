## 🌍 Family Travel Tracker
A web application that allows families to track their travel history on an interactive map! Users can add family members and mark the places they’ve visited. The data is stored in PostgreSQL, and the map dynamically updates to visualize each family member’s travel journey.

🚀 Features :- 

✅ Add new family members

✅ Store and manage travel history in PostgreSQL

✅ View an interactive world map with marked locations

✅ User-friendly interface built with EJS & JavaScript

🛠️ Tech Stack :-  

Frontend: HTML, CSS, JavaScript, EJS

Database: PostgreSQL
